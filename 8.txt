Example:
STEP 1: Create One Custom Object
Click Setup (⚙) → Object Manager
Click Create → Custom Object
Enter:
Label: Note
Plural Label: Notes
Record Name: Note Name (Text)
Click Save
✔ Done — your object is created!

 STEP 2: Create a Tab
Setup → Tabs
Under Custom Object Tabs, click New
Select Note
Choose any icon
Click Save
 Now your object is visible to users.

 STEP 3: Create a Simple App
Setup → App Manager
Click New Lightning App
App Name: Notes App
Click Next 2–3 times (do nothing)
Add Notes to the Navigation Items
Click Save & Finish
Nowapp is ready!
